# sdlc-next（保存 / 交接 / 回退）

读取用户主目录下 **`.sdlc/skill-core.md`** 并完整遵循——特别是触发映射、plan/apply 协作（§3）、顺序与发布（§3.3）与对话输出规范（§0）。

本命令三个意图：

- 保存（缺省）：`sdlc next --intent save --auto`——commit → push → 发布流程记录；不建 PR、不推进阶段。
- 交接（用户明确说）：`sdlc next --intent handoff --auto`——任务同步 → PR（预填链接人工创建，链接回填对话）→ 阶段推进 → 交接话术（全链）。
- 回退：`sdlc next --request-change "<说明>"`——说明留痕，`--to` 只从计划候选选（保留确认路径，不走 --auto）。

**`--auto` 直通（直通白名单）**：保存与交接是高频低风险动作（本需求分支可回退），用户说「保存」/「交接」就是确认——直接带 `--auto` 执行并转述结果，**不要再出计划等确认**；失败即停如实转述。归档（done）、回退、PR 回填仍走 plan 确认。

已授权的 brief 在交接前起草；DoD 缺口集中展示，接受继续即可。

转述时用自然语言描述动作与缺口；命令、flag 与 plan_id 不出现在给用户的文字里。
