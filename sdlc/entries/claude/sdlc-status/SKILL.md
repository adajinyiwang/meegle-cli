# sdlc-status（只读快照）

读取用户主目录下 **`.sdlc/skill-core.md`** 并完整遵循——特别是触发映射、排错与话术（§6）与对话输出规范（§0）。

本命令：`sdlc status [<req_id>]`。按 req_id 可定位已归档需求。话术取自实际已发布结果，不补写事件、不重发。

展示用简洁摘要（阶段 / 缺口 / PR / 待办各一行），不照搬 CLI 全文；`--json` 机读输出仅供你解析用。
