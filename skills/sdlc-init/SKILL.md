# sdlc-init（仓库接入）

读取用户主目录下 **`.sdlc/skill-core.md`** 并完整遵循——特别是触发映射、plan/apply 协作（§3）与对话输出规范（§0）。

本命令：`sdlc init`（预览 → 确认 → `--apply` 写入）。仓库仅一份轻配置，`start` 不代建配置。

转述时用自然语言描述将生成的文件与用途，用户确认后由你执行 apply；命令与 plan_id 不出现在给用户的文字里。
